# Youtube 视频字幕处理工具

这是一个本地视频处理工具，用于下载或读取视频，生成字幕、翻译字幕、校正字幕，并逐步扩展到字幕烧录和内容切片。

## 当前能力

- 下载视频和说明信息。
- 下载内容可按复选框分别选择：视频、音频、封面、简介、链接标题。
- 音频统一输出兼容 Windows 播放器的 MP3，保存在 `02_audio`。
- 生成中英双语字幕。
- 烧录字幕到视频。
- 读取本地视频、音频或 SRT 字幕。
- 只使用在线识别 API 导出带时间轴的 SRT。
- 火山在线识别支持极速版本地文件直传和标准版音频 URL 模式。
- 合并短句。
- 智能拆分过长字幕，按标点、连接词和从句边界控制单条字幕长度。
- 使用大模型检查英文识别结果。
- AI 检查结果可逐条手动调整，再一键校正。
- 翻译中文字幕。
- 导出英文、中文或中英双语字幕。
- 上传视频后可手动添加多个切片时间段，导出 MP4 切片和对应字幕。
- 切片区支持粘贴本地视频路径，不复制源视频，不必先跑字幕识别。
- 可开启对比翻译，使用第二套翻译 API 生成另一版中文译文用于对照。
- 按视频标题创建项目文件夹，整理源视频、音频、字幕、B 站简介和时间轴大纲。

## 启动方式

双击：

```text
打开网页版.bat
```

程序会启动本地网页版本。

## 长期更新文档

项目路线、已完成内容、后续计划都记录在：

```text
更新文档.md
```

## GitHub 上传规则

- 上传程序代码、页面、说明文档、字幕文本、项目记录。
- 不上传源视频、源音频、烧录成品视频、切片视频。
- 本地处理文件默认放在 `downloads` 下，只有未来 `downloads/projects` 里的文档、字幕和 JSON 记录会按需上传。

## 项目文件夹

下载或上传本地音频/视频时，会在下面创建项目：

```text
downloads/projects/视频标题/
```

主要子目录：

```text
00_source       原始信息、封面、info.json
01_video        源视频
02_audio        下载或抽取的音频
03_subtitles    平台字幕、原始识别字幕
04_description  B 站格式简介、时间轴大纲
10_translation  raw_en、corrected_en、zh、双语字幕
40_clips        后续切片结果
```

项目内视频的手动切片会输出到 `40_clips`，每个片段包含 MP4，若当前会话已有字幕，也会同步生成同时间段的 SRT。
如果使用“本地视频路径”作为切片来源，程序不会复制源视频，会在原视频所在目录创建 `<视频名>_clips` 文件夹保存切片。

## 在线识别

字幕工作台里的音视频识别只走在线 API，不再使用本机 Faster-Whisper。

- `火山极速版`：上传本地音频/视频，程序会转成识别用 MP3，必要时自动分段，再生成 `raw_en.srt`。
- `火山标准版 URL`：适合已经有公网音频链接的长文件，标准版不直接读取本地文件。

默认 Resource ID：极速版是 `volc.bigasr.auc_turbo`；标准版 1.0 是 `volc.bigasr.auc`，如果控制台显示 2.0，可手动改成 `volc.seedasr.auc`。

火山 API Key 只在本机浏览器输入，不写入项目文件，也不会上传到 GitHub。

## API 分工

- 识别 API：火山语音识别 Key，只用于把音频/视频转成英文字幕。
- 翻译 API：聊天/翻译大模型 Key，用于 AI 检查单词、校正英文、翻译中文、生成简介。
- 对比翻译 API：第二套聊天/翻译大模型 Key，仅在开启对比翻译时使用，用来生成另一版中文译文。

这两套 Key 不通用，界面里也分开填写。

## 一键生成

在线字幕工作台的“一键生成”会自动执行：

1. 读取并识别本地音频/视频，保存 `raw_en.srt`。
2. 合并过短字幕。
3. 智能拆分过长字幕，保存 `split_en.srt` 或 `merged_en.srt`。
4. 使用翻译 API 检查英文术语和识别错误。
5. 应用校正。
6. 翻译中文。
7. 按当前导出模式生成英文、中文或双语 SRT。

## 手动切片

上传并读取视频后，可以在“视频切片”区域添加多个时间段。时间支持：

- `90`：第 90 秒
- `01:30`：1 分 30 秒
- `00:01:30.500`：1 分 30.5 秒

导出后，程序会在项目 `40_clips` 目录生成 `clip_01_标题.mp4` 和对应 SRT。

如果只想切视频，不想先识别字幕，可以在“视频切片”区域粘贴本地视频完整路径，再添加时间段导出。路径模式不会复制源视频，切片输出到原视频同目录的 `<视频名>_clips` 文件夹。

## 目标流程

1. 下载或读取源视频。
2. 保留源文件和原始信息。
3. 识别字幕并生成带时间轴的 SRT。
4. 合并短句并智能拆分过长字幕。
5. 使用大模型校正英文。
6. 翻译中文字幕。
7. 导出字幕和烧录视频。
8. 根据内容生成 10 个 2-5 分钟切片候选。
9. 用户调整后导出最终切片。
